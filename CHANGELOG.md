# Changelog

## 2026-10-26

- Adjusted the app icon brightness to improve visibility.
- Simplified the chat layout and improved the default assistant/quick-access presentation.

> Comparison (before vs after):
>
> - Before: the interface was more compact and the default assistant / chat switching area was less visually distinct, making the layout feel crowded and harder to scan.
> - After: the main chat area and side panel are clearly separated, the current assistant is easier to identify, and the action controls are more readable and easier to use.
>
> This change makes the app feel closer to a cleaner “chat-first” layout while keeping the same core functionality.
>
> Example of the updated pattern:
>
> - Before: single-pane chat view with a more minimal, less structured layout.
> - After: split layout with a clearer sidebar, better distinction between chat list and assistant controls, and a more polished default assistant flow.

> Upstream changes are intentionally not listed here, in accordance with the README.
